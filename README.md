this program will grab the current playing song from lanyards api, you will need to have your spotify connected to your discord and be in the lanyard discord server - https://discord.gg/lanyard

how to use:
windows : open start.bat
linux : open terminal and run "./start.sh"

how to close: 
right click system tray icon

how it works: 
current playing song from lanyard api > lrclib > program > discord application that will show the current lyrics
